# The Strategy Room — V3 Multi-Page Website

## Upload to GitHub Pages
1. Extract this ZIP.
2. Upload **everything inside the extracted folder** to the root of your GitHub repository.
3. Keep the `assets` folder exactly as it is.
4. Your repository root should contain:
   - index.html
   - about.html
   - systems.html
   - process.html
   - diagnostic.html
   - insights.html
   - faq.html
   - contact.html
   - four service pages
   - four insight pages
   - styles.css
   - script.js
   - assets/ folder
5. In GitHub: Settings → Pages → Deploy from branch → main → /(root).

All links are relative and designed to work on GitHub Pages project sites.
